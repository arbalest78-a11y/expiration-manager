# 賞味期限管理アプリ

食品の賞味期限を登録し、期限が近い商品を分かりやすく確認できるWebアプリです。  
PC・スマートフォンの両方から利用できます。

## 主な機能

- 商品の登録
- 商品情報の編集・削除
- 商品画像の登録・削除
- 商品名による検索
- 賞味期限順・商品名順での並び替え
- 収納場所による絞り込み
- 賞味期限までの残り日数表示
- 賞味期限に応じたカードの色分け
  - 期限切れ
  - 2日以内
  - 7日以内
  - それ以外
- 期限ごとの件数表示
- 期限ごとのサマリーをクリックした絞り込み
- スマートフォン向けレイアウト

## 登録できる情報

- 商品名
- 賞味期限
- 個数
- 収納場所
- 商品写真
- メモ

## データの保存について

登録した商品データはブラウザの localStorage に保存しています。

そのため、同じブラウザではデータが残りますが、
PCとスマートフォンなど異なる端末間ではデータを共有できません。

## 今後の改善予定

- PCとスマートフォン間での商品データ共有
- データベースを利用した保存
- カメラやバーコードを利用した商品登録
- スマートフォンでの操作性のさらなる改善

## 制作目的

JavaScriptを使用したWebアプリ制作を通して、
商品データの登録・編集・削除、検索、絞り込み、
localStorageを使用したデータ保存、
レスポンシブ対応などの実装を学ぶために制作しました。
