# 賞味期限管理Webアプリ

食品などの賞味期限を登録・管理するためのWebアプリです。

商品ごとの賞味期限や収納場所、個数などを登録し、
期限までの日数や期限の近さを一覧で確認できます。

## 主な機能

- 商品名・賞味期限・収納場所・個数・メモの登録
- 登録した商品の編集・削除
- 商品画像の登録・表示
- 商品名による検索
- 賞味期限順・商品名順での並び替え
- 収納場所による絞り込み
- 賞味期限までの残り日数を表示
- 賞味期限の状態によってカードの背景色を変更
  - 期限切れ
  - 2日以内
  - 7日以内
  - それ以外
- 賞味期限の状態ごとの件数表示・絞り込み
- localStorageを利用したデータ保存
- JSONファイルによるデータのバックアップ・復元
- スマートフォン表示対応

## データのバックアップ・復元

登録した商品データは、ブラウザの `localStorage` に保存しています。

「データを書き出す」ボタンから、
現在登録されている商品データをJSONファイルとして保存できます。

「データを読み込む」ボタンから、
保存したJSONファイルを読み込み、商品データを復元できます。

ブラウザのデータが削除された場合のバックアップや、
別の環境へデータを移す場合に利用できます。

## OCR機能（試作・検証中）

商品画像から商品情報を読み取って登録することを目的として、
PythonとTesseract OCRを使用したOCR機能を試作しています。

現在は、商品画像から文字を読み取り、
賞味期限を抽出して商品登録フォームへ反映する処理を検証しています。

### 現在の課題

商品のパッケージ画像では、

- 背景の模様
- 文字の装飾
- 光の反射
- パッケージの曲面
- 賞味期限の小さい文字
- 撮影する位置や角度

などの影響により、OCRの読み取り精度が安定しない場合があります。

画像の前処理や複数のOCR方式を試しましたが、
処理負荷や読み取り精度の問題があるため、
現在OCR機能の開発は一旦保留しています。
