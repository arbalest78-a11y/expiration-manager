# 賞味期限管理Webアプリ

食品などの賞味期限を登録・管理するためのWebアプリです。

## 主な機能

- 商品名・賞味期限・収納場所・個数の登録
- 登録した商品の編集・削除
- 商品検索
- 賞味期限による並び替え
- 収納場所による絞り込み
- 賞味期限までの残り日数を表示
- 賞味期限の状態によってカードの背景色を変更
- localStorageを利用したデータ保存
- 商品画像からのOCR読み取り

## OCR機能

PythonとTesseract OCRを使用し、商品画像から文字を読み取る機能を実装しています。

現在は、読み取った文字列から商品名や賞味期限を抽出して、
商品登録フォームへ反映する処理を試しています。

### 現在の課題

商品のパッケージ画像では、

- 背景の模様
- 文字の装飾
- 光の反射
- パッケージの曲面
- 賞味期限の小さい文字

などの影響により、OCRの読み取り精度が安定しない場合があります。

画像の前処理やOCR方式の変更など、精度向上の方法を検証しています。
