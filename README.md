# 賞味期限管理アプリ

食品の賞味期限を登録し、期限が近い商品を分かりやすく確認できるWebアプリです。  
PC・スマートフォンの両方から利用できます。

## 主な機能

- 商品の登録
- 商品情報の編集・削除
- 商品画像の登録・削除
- 商品名による検索
- 賞味期限順・商品名順での並び替え
- 収納場所による絞り込み
- 賞味期限までの残り日数表示
- 賞味期限に応じたカードの色分け
  - 期限切れ
  - 2日以内
  - 7日以内
  - それ以外
- 期限ごとの件数表示
- 期限ごとのサマリーをクリックした絞り込み
- スマートフォン向けレイアウト

- 商品名
- 賞味期限
- 個数
- 収納場所
- 商品写真
- メモ

# 賞味期限管理アプリ

食品の賞味期限や収納場所を登録し、一覧で管理できるWebアプリです。

賞味期限までの日数に応じて商品カードの色を変更し、
期限が近い商品を分かりやすく確認できるようにしています。

PC・スマートフォンの両方で利用できます。

## 公開ページ

https://arbalest78-a11y.github.io/expiration-manager/

## 主な機能

### 商品管理
- 商品の新規登録
- 登録した商品の編集
- 商品の削除
- 商品写真の登録
- 商品写真の削除

### 登録できる情報
- 商品名
- 賞味期限
- 個数
- 収納場所
- 商品写真
- メモ

### 賞味期限の表示

賞味期限までの日数によって、商品カードの背景色を変更します。

- 期限切れ
- 2日以内
- 7日以内
- それ以外

「あと○日」「今日まで」「期限切れ」など、
賞味期限までの残り日数も表示します。

### 検索・絞り込み
- 商品名による検索
- 収納場所による絞り込み
- 賞味期限の状態による絞り込み
- 賞味期限が近い順に並び替え
- 商品名順に並び替え
- 絞り込み条件の一括解除
- 現在表示している商品の件数表示

賞味期限のサマリーをクリックすることで、
「期限切れ」「2日以内」「7日以内」「それ以外」の商品だけを
表示することもできます。

## データ保存

登録した商品データはブラウザの `localStorage` に保存しています。

そのため、ページを閉じたり再読み込みした場合でも、
同じブラウザであれば登録内容を保持できます。

※ サーバーやデータベースへの保存には現在対応していません。

## スマートフォン対応

画面幅が小さい場合は、

- 商品登録フォームを1列表示
- 検索・絞り込み項目を縦並び
- 編集・削除ボタンを横並び
- 商品画像を小さく表示

するなど、スマートフォンでも操作しやすいレイアウトにしています。
